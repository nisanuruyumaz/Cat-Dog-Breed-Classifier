# Cat-Dog Breed Classifier

## Proje Hakkında
Bu proje, derin öğrenme ve bilgisayarlı görü
teknikleri kullanarak kedi ve köpeklerin
cinslerini sınıflandırmayı amaçlamaktadır.

## Kullanılan Teknolojiler
- Python
- TensorFlow
- Keras
- Google Colab
- NumPy
- Matplotlib

## Projenin Aşamaları
- Veri setinin hazırlanması
- Veri ön işleme
- Model eğitimi
- Model performansının değerlendirilmesi
- Görüntü üzerinden cins tahmini
